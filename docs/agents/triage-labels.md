# Triage labels

Use these strings in each ticket's Status field.

| Role | Tracker status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | Will not be implemented |

These labels describe triage readiness. Track implementation
progress and completion separately.
