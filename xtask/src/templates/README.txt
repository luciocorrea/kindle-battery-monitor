Kindle battery monitor {version}

Tested Paperwhite 4 firmware 5.16.5 only.
Extract the kindle-battery-monitor directory into Kindle/extensions/.
Open KUAL > Kindle battery monitor > Install/update.
Restart with USB disconnected; wait for Home/KUAL before reconnecting.
Enable/Disable change automatic startup and the current session.
Start/Stop change only the session. Status shows both.
Updates preserve both settings. Wait for completion before another action.
Uninstall requires confirmation and removes the entire extension and boot job.
Home Assistant history remains intact.
Keep a copy of this ZIP outside the Kindle if you want to reinstall.
Do not delete the extension directory while the boot job is installed.
If recovery is reported, inspect the result before invoking Install/update again.
